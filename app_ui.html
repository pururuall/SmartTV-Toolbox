ByeDPI: Локальный обход YouTube (Без VPN и внешних серверов)
Что такое ByeDPI и как он работает?
ByeDPI — это локальная утилита, которая запускается прямо на процессоре вашего телевизора и создаёт локальный SOCKS5 прокси на адресе 127.0.0.1:1080. Она расщепляет первый сетевой пакет TLS ClientHello на части. Фильтры ТСПУ провайдера не могут прочесть доменное имя googlevideo.com и пропускают видеопоток на полной скорости домашнего интернета.
📖 Пошаговая инструкция настройки ByeDPI:
Шаг 1: Установите и запустите приложение ByeDPI на телевизоре. Нажмите большую круглую кнопку «Подключить» (Connect).
Шаг 2: Откройте SmartTube на телевизоре -> перейдите в Настройки (шестерёнка внизу левого меню) -> Общие -> Сеть / Прокси.
Шаг 3: Выберите тип прокси: SOCKS5, Адрес: 127.0.0.1, Порт: 1080.
Шаг 4: Видео на YouTube в SmartTube начинают моментально воспроизводиться в качестве 4K 60fps!
WireGuard VPN: Прямой импорт .conf файла с ПК на ТВ
У вас есть файл конфигурации WireGuard (.conf)?
Не нужно перепечатывать длинные ключи пультом! Выберите ваш файл .conf на компьютере — программа автоматически передаст его по Wi-Fi в папку /sdcard/Download/ на телевизоре и сразу откроет приложение WireGuard для быстрого импорта.
Файл не выбран
На ТВ нажмите [+] -> «Импорт из файла» -> выберите файл из Download
Happ Proxy / VPN: VLESS, Reality, Shadowsocks и Clash-подписки
У вас есть ссылка подписки Happ или VLESS ключ?
Приложение Happ (на базе XRay ядра) поддерживает самые современные протоколы обхода блокировок: VLESS с Reality, Trojan и Shadowsocks. Вставьте ссылку вашей подписки ниже — Toolbox автоматически передаст её в Happ на телевизоре.
💡 Ссылка будет открыта через прямой Intent в приложении Happ на экране ТВ, и профиль автоматически добавится в список серверов.
Шпаргалка по протоколам: Какой способ обхода выбрать?
⚡ ByeDPI (Локально)
Для чего: Только YouTube.
Плюсы: Бесплатно, без серверов, скорость не падает.
Как настроить: Запустить на ТВ + прописать 127.0.0.1:1080 в SmartTube.
🛡️ Happ (VLESS / Reality)
Для чего: Весь трафик ТВ, включая заблокированные кинотеатры.
Плюсы: Максимальная маскировка под обычные сайты, не блокируется провайдерами.
Формат: Ссылка подписки или vless:// ключ.
🔒 WireGuard (.conf)
Для чего: Собственный VPS сервер или готовые конфиги от друзей.
Плюсы: Очень высокая скорость, минимальная нагрузка на слабый процессор ТВ.
Формат: Файл с расширением .conf.

⚡ Инструкция к ByeDPI (YouTube без тормозов)

Как работает ByeDPI:
ByeDPI — это локальная утилита обхода блокировок. В отличие от обычного VPN, ей не нужен внешний сервер или подписка. Она разбивает заголовки TLS/TCP пакетов прямо на ТВ, благодаря чему провайдер перестаёт замедлять YouTube, Discord и другие сервисы.

Режимы работы:
1. VPN Mode (Простой): Включите переключатель VPN в приложении ByeDPI на ТВ и нажмите «Подключить».
2. Proxy Mode: Локальный Socks5 прокси (127.0.0.1:1080).
